Under the hood

How it works

Four moving parts, wired together in about 40 lines of Python.

  1. 1
    You speak

    AudioIO captures microphone audio with echo cancellation and noise suppression enabled via WebRTC — so open laptop speakers work fine.

  2. 2
    Strands BidiAgent streams it to Bedrock

    A persistent bidirectional WebSocket keeps latency low and lets you barge in while the model is still talking.

  3. 3
    Nova Sonic processes speech end-to-end

    The model hears your audio directly — no transcript in the middle — so it picks up tone, pacing, and energy, not just words.

  4. 4
    Audio streams back to your speakers

    The agent's voice comes through your speakers in real time. The same AudioIO instance that captures also plays back, sharing the echo-cancellation reference signal.

Get started

Run it on your laptop

You'll need Python 3.12+, PortAudio, and AWS credentials with Bedrock access in us-east-1.

1. Clone & install

# clone the repo
git clone https://github.com/Nok2lapatience/jozi-voice-buddy
cd jozi-voice-buddy

# create a virtual environment
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# install dependencies
pip install -r requirements.txt

2. Configure AWS & run

# configure AWS credentials
aws configure
# → region: us-east-1

# enable Nova Sonic in Bedrock console:
# Bedrock → Model access → Amazon Nova Sonic

# start the agent
python voice_agent.py

# press Ctrl+C to end the chat
